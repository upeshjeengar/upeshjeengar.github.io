The core idea

Training data is not just collected. It is designed.

Real-world data is messy and can have biases caused during collection, sampling, or labeling. Because of this, it often requires days of cleaning and processing before we can create representative train and test splits.

A model learns from the data distribution it sees. If the sample is biased, the labels are noisy, or the split is not representative, the model will inherit those problems.

Sampling

For most ML problems, we train on a sample of available data.

We usually cannot train on all the data present for a general ML problem. Instead, we create a sample and treat that sample as our full dataset. The sampling method decides what kinds of bias may enter the project.

Non-probability sampling

  • Convenience sampling: samples are selected based on availability.
  • Snowball sampling: future samples are selected based on existing samples.
  • Judgment sampling: experts decide which samples to include.
  • Quota sampling: a fixed number of samples is taken from each group, such as age groups.

Probability-based sampling

  • Simple random sampling: randomly select a portion of all samples.
  • Stratified sampling: divide data into important groups and sample from each group.
  • Weighted sampling: assign sampling weights using domain knowledge.
  • Reservoir sampling: keep a sample from continuously incoming data.
!
Selection bias

Non-probability sampling can be a quick and easy way to gather initial data and get a project off the ground, but these samples are usually not representative of real-world data and can be riddled with selection bias.

Simple random sampling

Randomly selecting 10% of all samples is simple, but rare categories may not appear. This can create a data imbalance problem for the ML model.

Stratified sampling

Divide data into groups we care about, such as class A and class B, and then select a percentage of samples from each group.

Weighted sampling

In weighted sampling, each sample gets a weight based on domain knowledge or sampling requirements.

random.choices(
    population=[1, 2, 3, 4, 100, 1000],
    weights=[0.2, 0.2, 0.2, 0.2, 0.1, 0.1],
    k=2
)  # pick two items with specified probabilities

Importance sampling

Suppose a distribution is hard or costly to sample from, say P(x). Instead, we sample from a convenient distribution Q(x) and reweight the examples.

E_P[x] = sum_x P(x)x

E_P[x] = sum_x Q(x)x * P(x) / Q(x)

E_P[x] = E_Q[x * P(x) / Q(x)]

In simple terms, imagine you want information about millionaires, but millionaires are hard to find and expensive to contact. Instead, you survey random people because they are easier to reach. Since that survey does not represent millionaires correctly, you give more weight to responses from people who are more likely to be millionaires and less weight to others. That is essentially importance sampling.

Reservoir sampling

Reservoir sampling is used for continually incoming data. For example, if you want a continuous sample of k tweets, first select the first k tweets and store them in an array. Then, for each incoming nth element, generate a random number i between 1 and n. If i <= k, replace the ith element in the sample with the nth element.

Labeling

For many tasks, natural labels are not available.

For most tasks, natural labels are not available or not accessible, and we need to obtain labels by other means.

Hand labels

Hand labeling can be expensive if it requires subject matter experts. It can also be slow and may create privacy risks.

Label multiplicity

Data from different sources or annotators can have different accuracy levels. To reduce disagreement, start with a clear problem definition.

Data lineage

Mark the source of each data sample. This helps flag potential bias in the data and makes model debugging easier.

Weak supervision

Weak supervision relies on heuristics that can be developed with subject matter experts. For example, a doctor may look for a specific keyword in a report. A labeling function is a function that encodes such heuristics.

Possible heuristics include keyword rules, regular expressions, database lookups, and outputs from other models. A small, high-quality hand-labeled dataset can help you write better labeling functions.

Semi-supervision

Semi-supervised learning is based on the assumption that small perturbations to a sample should not change its label. For example, if we add a small amount of white noise to an image, the label should usually remain the same. We can use this as a data augmentation technique when we have a small labeled dataset.

Transfer learning

Transfer learning adapts a model trained on a larger pool of knowledge to a smaller downstream task, such as adapting a language model to sentiment analysis or intent detection.

Active learning

Instead of randomly labeling data samples, active learning labels the samples that are most helpful to the model according to some heuristic.

Another common heuristic is based on disagreement among multiple candidate models. This method is called query-by-committee. You train several candidate models, often the same model with different hyperparameters. Each model votes on which examples should be labeled next, often based on uncertainty. You then label the examples that the committee disagrees on the most.

Class imbalance

Imbalanced classes can make the model prefer the majority class.

Class imbalance happens when the number of samples in each class differs heavily. This can make the model biased toward the majority class.

1

Choose the right metric

Decide whether the problem cares more about precision, recall, or another metric. For example, precision is TP / (TP + FP), while recall is TP / (TP + FN). ROC curves can help decide the model threshold.

2

Use data-level methods

Change the distribution of the data to make it less imbalanced. SMOTE creates synthetic minority-class samples by sampling convex combinations of existing minority-class points.

3

Use robust algorithms

Cost-sensitive learning penalizes misclassifying the minority class more heavily. In scikit-learn, class_weight='balanced' follows this idea.

Data augmentation

Augmentation increases training examples synthetically.

Data augmentation is especially useful when we need more minority-class examples or when labeled data is limited. The key requirement is that the transformation should preserve the label.

Label-preserving transformations

For images, we can flip, crop, or rotate slightly while maintaining the same label. For text, we can replace words with similar words to create more sentences.

Perturbation

Neural networks are sensitive to noise. In computer vision, even a single-pixel change can sometimes make a model misclassify an image.

Data synthesis

In NLP, templates can generate many examples. In computer vision, methods such as mixup combine existing examples and labels.

Template-based synthesis

In NLP, we can use a template such as: Find me a [CUISINE] restaurant within [NUMBER] miles of [LOCATION]. Replacing those three placeholders creates many different sentences.

Mixup

In computer vision, one way to synthesize new data is to combine existing examples with discrete labels to generate continuous labels. Consider a task of classifying images as DOG, encoded as 0, and CAT, encoded as 1. From example x1 with label DOG and example x2 with label CAT, we can generate:

x' = gamma * x1 + (1 - gamma) * x2

label(x') = gamma * 0 + (1 - gamma) * 1

This method is called mixup. The authors showed that mixup improves model generalization, reduces memorization of corrupt labels, increases robustness to adversarial examples, and stabilizes the training of generative adversarial networks.

Summary

Better training data leads to better ML systems.

Training data is the foundation of machine learning, and its quality largely determines model performance. This blog discussed how to create effective training data through proper sampling methods and labeling techniques.

Since manual labeling can be expensive and time-consuming, alternatives such as weak supervision, semi-supervised learning, transfer learning, and active learning can reduce labeling effort. The blog also covered class imbalance, a common real-world challenge, and presented solutions such as resampling, appropriate evaluation metrics, and modified loss functions.

Finally, we covered data augmentation techniques for computer vision and NLP tasks to improve model accuracy and generalization. The next step after preparing training data is feature extraction.
