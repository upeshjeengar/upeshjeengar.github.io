Getting Started With the Portfolio Blog

This is a starter HTML blog post. The homepage blog section reads metadata from blogs/blogs.json, so future writing can stay simple: add a new HTML file in this folder and add one JSON object with its title, date, summary, and relative link.

A useful structure is to write about projects after they are complete: what problem you solved, what constraints mattered, what you measured, and what you would improve in the next version.

That keeps the portfolio more alive than a list of repositories. It also makes your engineering judgment visible.
